# Установка и первый запуск, который проходит без автора

Дата: 2026-08-03. Часть A из трёх; B — шаги в интерфейсе, C — сама заливка.

## Кому и зачем

Пользователи — 2–10 аналитиков отдела, не программисты, свои Windows-машины без
прав администратора. Папку проекта получают через `git clone`. Есть ли на их
машинах Python — неизвестно, поэтому решение обязано работать в обоих случаях.

Успех: коллега клонирует репозиторий, запускает один файл и доходит до
загруженной таблицы, ни разу не позвав автора.

## Что сейчас ломается

**Установка останавливается на совете.** `loader.bat` ищет `uv` на `PATH` и в
каталоге пользовательских скриптов Python — эта логика работает и остаётся. Но
если `uv` не найден, файл печатает две команды и выходит. Коллега, у которого
Python есть, вынужден копировать команду вручную, хотя её мог выполнить сам
загрузчик.

**Порт проверяется слишком поздно.** Занятый 8501 обнаруживается после старта
Streamlit: ветка `:streamlit_failed` советует закрыть процесс и запустить снова.

**Устаревшая копия ничем не отличается от свежей.** При `git clone` обновление —
это `git pull`, но ничто об этом не напоминает, и коллега может неделями работать
на старом коде, включая уже исправленные тихие порчи данных.

**README описывает интерфейс, которого нет.** Проверено чтением `app.py`:

- шаг 13 велит нажать `Analyze CSV` — такой кнопки не существует;
- `Apply parameters` стоит шагом 11, до чтения CSV, а в приложении параметры
  формы появляются только после подтверждения типов;
- два обязательных шага, `Apply column mapping` и `Apply types`, не упомянуты
  вовсе, поэтому идущий по README застревает;
- список поддерживаемых типов отстал на шесть значений: нет `Decimal(38, 0)`,
  `Decimal(76, 0)`, `Decimal(38, 2)`, `Decimal(76, 2)`, `Decimal(76, 10)`,
  `Date32`;
- сказано, что ключ шардирования по умолчанию `rand()`; в коде этого больше нет,
  ключ выбирается из колонок.

## Решение

### 1. Загрузчик доводит дело до конца

`loader.bat` отвечает только за то, что обязано работать ДО появления
окружения, — за `uv`:

1. найти `uv` (существующая логика, не меняется);
2. если не найден и найден Python — поставить самому:
   `py -3.12 -m pip install --user uv`, затем искать снова;
3. если Python тоже не найден — показать ровно одну команду и остановиться;
4. выполнить `uv sync --locked --extra dev` (не меняется);
5. передать управление `csv_click.launcher`.

Всё, что происходит после установки окружения, уходит в Python-модуль
`src/csv_click/launcher.py`: там уже есть `.venv`, и логику можно проверять
исполнением, а не чтением текста `.bat`.

### 2. `csv_click.launcher` — запуск и предупреждения

Модуль запускается как `python -m csv_click.launcher` и делает три вещи:

- **выбирает порт.** Пробует 8501; занят — берёт следующий свободный в пределах
  десяти попыток и печатает выбранный адрес. Если свободного нет, печатает, что
  занято, и завершается с ненулевым кодом;
- **сообщает о свежести копии.** Если рядом есть `.git` и ссылка на удалённую
  ветку уже скачана, сравнивает с ней локальный `HEAD` и печатает одну строку с
  командой `git pull`, когда копия отстала. Сеть не трогается: запуск не должен
  зависеть от доступности GitHub. Если ссылки нет — например, `git fetch` ни
  разу не выполнялся, — модуль молчит, а не выдумывает вердикт. Это
  предупреждение, а не блокировка: работать на старой копии иногда нужно
  осознанно;
- **запускает Streamlit** тем же интерпретатором из `.venv`.

Любая своя ошибка печатается человеческим текстом, без трассировки Python:
трассировка для этих пользователей — тупик.

### 3. README перестаёт врать и становится коротким

- В начало — «Первый запуск за три шага»: клонировать, запустить `loader.bat`,
  открыть напечатанный адрес.
- Раздел «Как пользоваться» переписывается по фактическим кнопкам и фактическому
  порядку, с `Apply column mapping` и `Apply types` на своих местах.
- Список типов приводится в соответствие с `CLICKHOUSE_TYPE_OPTIONS`.
- Утверждение про `rand()` удаляется.
- Раздел про обновление копии: `git pull`, и что загрузчик об этом напомнит.

## Проверяемость

Главное решение: README проверяется тестами, а не вниманием. В проекте уже есть
`tests/test_loader_bat.py` с двумя тестами про README — подход продолжается.

| Что проверяется | Как |
|---|---|
| Каждое название кнопки, упомянутое в README, существует в `app.py` | тест сверяет строки в бэктиках со `st.button`/`form_submit_button` |
| Обязательные шаги описаны | тест требует `Apply column mapping` и `Apply types` в README |
| Список типов в README совпадает с `CLICKHOUSE_TYPE_OPTIONS` | тест сверяет множества |
| Занятый порт не мешает запуску | тест занимает сокет и вызывает выбор порта |
| Отставшая копия распознаётся | тест на временном репозитории с двумя коммитами |
| Загрузчик ставит `uv` сам | текстовый тест на ветку в `.bat` |
| Загрузчик передаёт управление модулю | текстовый тест на вызов `csv_click.launcher` |

Существующий `test_loader_bat_launches_streamlit_from_the_project_venv`
обновляется: запуск Streamlit переезжает в модуль, поэтому проверка запуска
переезжает в тест модуля.

Метод сессии применяется как обычно: тест первым, мутационная проверка с гашением
кэша байткода и восстановлением всех тронутых файлов, состязательное ревью дифа.

## Границы

Не входит в часть A:

- **подключение к ClickHouse.** Коллеги с ним справляются. Отдельно замечено:
  дефолтные пути сертификатов в полях — линуксовые (`/home/jovyan/tsh/...`) и на
  Windows бессмысленны; это уходит в часть B;
- **шаги интерфейса и подсказки** — часть B;
- **отмена загрузки, живой прогресс, внятные ошибки** — часть C;
- **упаковка в exe или установщик.** `git clone` плюс `uv` уже работают, а
  сборка дистрибутива на машине без прав администратора создаст больше проблем,
  чем решит.

## Риски

`loader.bat` невозможно прогнать в тестах целиком: он ставит `uv` и меняет
окружение машины. Поэтому логика и разделена — всё проверяемое исполнением ушло
в Python, а в `.bat` осталась минимальная часть, которую проверяет чтение текста.
Эту часть придётся один раз прогнать вручную на машине без `uv`; проверить это
локально нельзя, и в отчёте будет сказано прямо, что она проверена только текстом.
